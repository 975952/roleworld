## 1. 这个产品现在是什么

本地优先的角色对话应用：没有账号、没有后端、没有遥测；浏览器 IndexedDB（网页版）或
`%APPDATA%\app.roleworld.desktop\data\`（桌面版）存全部数据；请求从用户设备直连他配置的模型端点。

**产品底线**（用户自己定的，改动前先确认不要踩）：

1. **真实信息与虚构剧情分开存**：事实 / 事件 / 剧情三种 `rw_source.kind`，注入时分别无前缀、`[此前发生]`、`[剧情]`；
2. **记忆必须可查可改可删**：每条记忆带来源（哪段对话第几条），面板能「看原话」「说得对」「改」「删」；
3. **不操纵用户**：没有主动消息、连续打卡、好感度、冷落惩罚；伴侣模式里有"不许内疚留人"的硬规矩 + 自检；
4. **不知道就说不知道**：检索翻不到时机制上要求照实说，不许编造共同过去。

## 5. 已知的坑（都是真踩过的，按踩的顺序）

1. **`hidden` 属性没人摘**：顶栏「记忆」按钮带 `hidden` 且无代码摘除 → 用户永远点不到（0.1.18 修）。教训：入口按钮要有"看得见 + 真鼠标点击"的端到端用例，`element.click()` 对隐藏元素照样触发。
2. **端到端跑在被浮层盖住的界面上**：两个浏览器套件的 fixture 没设 `tutorial_seen`，首启引导浮层（`.rw-ob`，`position:fixed; inset:0`）一直盖着 → 几十条用例全在"真人点不到"的状态下跑。现在两个 fixture 都显式 `tutorial_seen: true`。
3. **`RoleWorld.init()` 在真实使用里没人调用**：把体验卡自动应用挂在那里等于挂在死路径上（只有测试显式调它）。现在 `bootLive → STApi.init → init()` 这条路是通的，且 `applyFromLocation` 在三处都跑。
4. **只改片段地址不重载页面**：`#card=` 链接在同一标签页里打开不会触发加载 → 必须有 `hashchange` 监听（已加）。
5. **`saveLocalSettings()` 只落盘、不通知页面**：测试里改完设置后必须 `dispatchEvent(new CustomEvent("roleworld:settings-changed", …))`，否则 `liveState` 还是旧值（这条也坑过一次用例）。
6. **新选项要过四道转发**：见 §2 表格里 `task22-core.js` 那一行。
7. **`describeRequest` 是逐字节核对**：系统提示里任何"多出来的那一行"都必须同步加到面板重建里（语言要求那行出现三次：开头 / 中间 / 结尾；强制语言时还多一条贴近输入的提醒），否则面板会诚实地说"数字不可信"。
8. **PWA 离线壳**：只比对线上 `version.json` 看不出浏览器里跑的是哪一版 → 现在 `app/build.js` 里编进版本号，「设置 → 关于 → 版本」显示"运行 X · 已是最新"，不一致会变红并给「检查更新」。
9. **云开发的三个坑**（体验卡部署时踩的，详见 NIGHT_LOG 第十轮）：
   - 云托管要先"开通"，CLI 没这命令 → `tcb api tcb CreateCloudBaseRunResource --body '{"EnvId":"…"}'`；
   - 「AI 工具中使用 Token」那页建的是**网关令牌**，Node SDK 拿它连库会 `INVALID_ACCESS_TOKEN`；环境级 ApiKey 要在「环境配置 → ApiKey 管理」建，再到云托管「API Key 设置」注入；
   - **这个环境是 PostgreSQL**，文档型数据库 API 会报 `no document database instance` → 账本走 `/v1/rdb/exec-pgsql` 建表 + `/v1/rdb/rest/{table}` 增删改查。
10. **Windows 上别用 PowerShell 改 JSON/版本号**：会写 BOM、引号会被吃 → 用 `node scripts/set-version.cjs`；同理别用 PowerShell 内联 JS（本项目所有一次性脚本都放 `scripts/*.cjs`，用完删）。
11. **测试偶尔会 flake**：比如"改了设置马上发请求"这种，要等一个**可观察的信号**（如「发送前预估」显示出新值）再发，别只等落盘。
12. **删除目录要小心长路径**：`Remove-Item` 在超长路径/被占用时会失败；不要跑全盘递归扫描（用户会烦）。
