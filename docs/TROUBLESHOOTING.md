# 故障排查手册

> 面向你（使用者）而不是开发者。每条都按「现象 → 是什么 → 怎么办」写。
> 涉及数据与密钥的说明以 `app/about.html`（设置 → 关于 → 查看说明）为准。

---

## 1. 打开线上站点，先看到一个"免费版/额度"提示页

**是什么**：那是 CloudBase 静态托管免费版自带的提示页，不是我们的页面，也不是应用出错。
点掉/跳过之后就能进应用。

**怎么办**：点提示页上的继续按钮即可。如果你不想再看到它，需要在 CloudBase 控制台升级托管套餐
（会产生费用），我这边无法代你决定。

---

## 2. 应用打不开 / 白屏

按这个顺序看：

1. **是不是断网了**：目前还没有离线包，断网打不开界面（你的数据还在本机，联网后照常）。
2. **强制刷新**：`Ctrl` + `F5`。
3. **看控制台**：`F12` → Console，如果有红色报错，把第一行发我。
4. **确认地址**：本机开发时是 `index.html`；线上是托管域名。别用 `file://` 直接打开
   （浏览器会禁止它读本地数据库）。

## 3. 发不出去消息

| 提示 | 含义 | 怎么办 |
|---|---|---|
| 输入框灰色、写着"正在准备对话…" | 角色卡 / 端点 / 会话三者还没齐 | 看设置 → 模型里端点是否填了；侧栏是否选中了角色 |
| 「尚未保存 DeepSeek API Key」 | 走 DeepSeek 通道但没填 Key | 设置 → 模型 → 填 Key → 保存（只存在本机） |
| 「这一轮超过了上下文上限，先看看上面的说明」 | 输入 + 输出上限超过了模型上下文 | 按提示做：调小历史预算 / 减少记忆条数 / 换上下文更大的模型 / 新开一段对话 |
| 「模型没有返回内容，请重试」 | 端点回了空内容 | 先重试一次；还不行就换模型名再试 |

**Key 无效 / 限流 / 余额不足怎么分辨**：
- `401 / 403` → Key 不对或没权限（重新粘贴一次，注意前后空格）；
- `429` → 请求太频繁，等一会儿；
- `402 / 余额` → 账户没钱了；
- 超时 / 连接被重置 → 网络或代理问题，不是 Key 的问题。

这些判断不影响你的数据：失败的这一轮**不会**写进对话，也不会计费（有用例盯着）。

## 4. 费用看起来不对

1. **先看口径**：鼠标悬停在输入框左下角那条费用行上，会写出币种、当前时段（高峰/空闲）、
   是否用了你填的自定义单价。
2. **高峰会翻倍**：北京时间周一至周五 9:00-12:00、14:00-18:00 是高峰，其余（含周末）是空闲。
3. **"≈" 是什么意思**：接口没回用量时按字数估算，数字前面会带 `≈`；接口回了就是真实值。
4. **发送前预估**：输入框左下角「这次约 N 输入 ≈ ¥x」就是发送前的预估值，
   它按上一轮真实用量 + 这一轮草稿算，不发额外请求。
5. **想省钱**：开缓存命中的前缀（同一套角色卡 + 记忆不要频繁改）、把输出上限调小、
   在空闲时段聊。改记忆/改角色卡会让缓存前缀失效。

## 5. 它记错了 / 它编造了

- **记错了**：回复旁边点「记错」，计入台账；再去「角色记忆」里找到那条删掉或改掉。
  删掉之后**下一轮请求里就真的不再带上它**。
- **编造了**：回复旁边点「编造」；如果它是把以前的事说错了，用回复下面的
  「引用了 N 条以前的记录」去看它到底引的是哪句。
- **它说"没有更早的记录"，但那件事明明说过**：历史检索是**关键词匹配**，不是语义搜索。
  换个说法（原话里的词）再问一次，命中率会高很多。
- **想让它改口**：直接说"我现在不喜欢这个了"。同主题的新说法会**替换**旧记忆，
  而不是两条并存。

## 6. 我的数据在哪 / 怎么备份

| 平台 | 位置 |
|---|---|
| 网页版 | 浏览器本机数据库（IndexedDB）。清浏览器数据会**一起清掉** |
| 桌面版 | 应用数据目录下的普通文件（角色、对话、记忆书、关系档案各一份），可以用资源管理器直接备份 |

- **备份**：设置 → 本地数据 → 导出存档。存档里**不含 API Key**，换机器要重新填一次。
- **恢复**：同一处导入。导入会按你选的模式覆盖或合并。
- **注意**：「本地保存」不等于「不上云」——对话内容会发给你配置的模型端点（详见关于页）。

## 7. 怎么回退到上一个版本

线上站点是有版本记录的静态托管：

1. 云端控制台 → 静态托管 → 历史版本，选上一个版本回滚；
2. 或者本地 `git log` 找到上一个提交，把 `roleworld/` 重新部署一次。

桌面端：Release 页面上保留着历史安装包，装回旧版即可（数据格式向后兼容，目前没有破坏性变更）。

---

## 8. 测试与自检

- 全量测试：在 `roleworld/` 下 `npm test`（8 个套件，约 4 分钟，全部离线、不碰真实模型）。
- 应用内自检：
  - 「本次请求」面板 → 看清这一次到底发了什么、各段多少字多少 token；
  - 「角色记忆」→ 看它到底记了什么、来自哪句话；
  - 「关系档案」→ 伴侣模式会遵守的那几条硬规矩，以及最近回复的内疚话术自检。

---

## 9. 我已经知道、暂时不打算改的

- 关键词检索翻不到语义近义的说法（这是取舍，不是 bug）；
- 剧情与事实的区分是启发式的，偶尔会把一句剧情当成你的事实拦下来（宁可漏记，也不误删你说过的话）；
- 伴侣模式的硬规矩写在提示词里，能大幅降低但不保证完全杜绝内疚话术；
- 没有跨设备同步、没有主动提醒、还没有离线包。
