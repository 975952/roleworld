## 0. 一句话结论

**先做"本机控制台"（`npm run console`，只监听 127.0.0.1），把 CLI 那几件事搬成网页；
不要把它放到公开的静态站点上。**

理由只有一条，但它是硬的：**控制台 = 发卡权 = 你的钱**。
每一轮对话都走你的 DeepSeek 账号，谁能发卡，谁就能花你的额度。

---

## 1. 三条不能踩的线

1. **不能进公开静态站点**。`tcb hosting deploy app` 传的是公开目录，任何人可访问；
   静态站点没有服务端，口令只能落在浏览器里 —— 谁打开控制台，谁就是发卡人。
   （现在中转的管理接口只认**一个** Bearer 口令 `ADMIN_SECRET`：没有二级权限、
   没有登录态、没有失败锁定、没有限速。它是"本机脚本用"的设计，不是"公网后台"的设计。）
2. **口令不进浏览器、不进仓库、不进日志**。和中转同一条规矩：账本只存 `sha256(卡号)`，
   日志只记用量不记正文。控制台默认把口令留在**本机服务进程**里。
3. **服务端永远拿不回卡号**（只有哈希）。所以"以后还能重印同学那段话"只有一条路：
   发卡时在**本机留一份卡号**（见 §4 P1-2）。不留就得承认"卡号只在发的那一刻显示一次"。

## 2. 三种形态（推荐 A）

| 形态 | 怎么用 | 代价 | 建议 |
|---|---|---|---|
| **A. 本机控制台** | `npm run console` → 浏览器打开 `http://127.0.0.1:8790`；口令由本机服务从 `relay/admin-secret.local.txt` 读，页面里没有口令 | 只能在这台电脑上用（手机不行）；关机就没了 | **先做这个** |
| B. 网页版里的隐藏页 + 手输口令 | 放进 `app/`，打开要输口令，存 sessionStorage | **公开可访问**：谁都能试口令；必须配强口令 + 中转限速 + 失败锁定 | 不建议 |
| C. 云托管网关 | 控制台并进 relay（`/admin-ui`），口令只在服务端环境变量里，自己加登录态 | 多一层鉴权要做对（会话 / CSRF / 限速）；云托管按量计费 | 以后要手机用再上 |

A 的数据流（没有任何新服务）：

```
浏览器(127.0.0.1:8790) → 本机 console 服务（持口令） → 中转 /admin/*（HTTPS）
```

## 3. 功能清单（按价值排）

### P0 —— 第一版就是"把 CLI 搬成网页"

1. **卡列表**：标签 / 已用∶上限 / token 用量 / 到期 / 状态 / 最后使用时间；
   搜索、排序；`剩 ≤3 次`、`已用完`、`已停用`、`已到期` 自动高亮。
2. **发卡**：标签、次数、token 上限、天数、张数（1–50）→ 一次生成。
   每张卡旁边一个「复制那段话」按钮，内容与 `card-cli.cjs` 的 `shareText()` **同一份**
   （一键链接 + 可整行粘贴的 `卡号@中转地址` + 隐私说明）。
3. **停用 / 启用 / 吊销**：点一下即生效，吊销要二次确认（不可逆）。
4. **中转状态条**：`/healthz` 一眼看（存活 / 账本类型 / 上游 key 是否配好）。

### P1 —— 让"发出去的卡"可以维护

5. **加次数 / 续期**：`PATCH /admin/cards/:id`（改 `quota.calls` / `quota.tokens` / `expiresAt`）。
   同学用完了就地补，**不用换卡、不用他重新配**。
   ⚠ 中转**现在没有这个接口**，要新增（服务端 + `relay-check` 用例）。
6. **本机留存卡号**（可选开关，默认关）：存 `relay/cards.local.jsonl`（`.gitignore` 里
   与 `relay/*.local.txt` 同级），控制台可导出/导入。开了它才能"重印那段话 / 核对是谁在用"。
7. **自检按钮**：`/admin/store/selftest`、`/admin/upstream/selftest` ——
   把现在要 curl 的三条做成绿/红两块。

### P2 —— 用的数据

8. **按天用量**：账本现在只存**累计** `used`。要看"今天用了几次/token"，得让中转按天累加
   （新表或从日志聚合）。
9. **异常提示**：同一张卡短时间大量调用、出现不在白名单的模型名、401/402 激增 → 标红。
10. **导出 CSV**（对账）。

## 4. 技术上要注意的

- **写入要防手滑**：发卡是 `POST`，重试/双击会多发一张。第一版就加"最近发出"本地列表 + 按钮 3 秒禁用。
- **不引依赖、不引框架**：沿用现在的做法（Node 标准库 + 原生 DOM），页面是死文件。
- **端口与绑定**：默认 `127.0.0.1:8790`，被占用自动 +1 并把真实地址打印到终端；**永远不绑 0.0.0.0**。
- **日志**：控制台不打印卡号明文；口令不进任何日志。
- **测试**：新增第 11 个套件 `tests/console-check.cjs`，起本机 console + 假中转（照 `relay-check.cjs`
  的假上游做法），断言：① 列表渲染 ② 发卡返回的文案含 `@中转地址` ③ 停用/启用/吊销 ④ 加次数/续期
  ⑤ **页面 HTML 与日志里都没有口令** ⑥ 只监听 127.0.0.1、没绑公网。
- **与 CLI 的关系**：CLI 不删。控制台是它的壳，两边共用同一份 `shareText()`/接口封装
  （把现在 `scripts/card-cli.cjs` 里的 HTTP 调用抽成 `relay/admin-client.js`，CLI 与控制台都 require 它）。

## 6. 需要用户拍板的

1. 形态：**A（本机，推荐）** / B（网页版隐藏页，风险自负） / C（云托管，手机也能用）。
2. 要不要**在本机留存卡号**（P1-6）：留了方便重印与对账，代价是这个文件等于凭据，要自己保管好。
3. 要不要**续期/加次数**（P1-5）：要的话中转要加一个接口并重新部署一次（云托管按量计费，可忽略）。

## 7. 已实现（2026-09-12，用户：「控制台按你推荐的来，好用就行」）

**A 档 + P0 落地**，新增/改动这些文件：

| 文件 | 干什么 |
|---|---|
| `scripts/console.cjs` | 本机控制台服务：只绑 `127.0.0.1`（默认 8790，被占用自动 +1），`npm run console` 启动；口令只在这个进程里 |
| `console/index.html` `console.css` `console.js` | 界面：发卡（标签/次数/token/天数/张数 + 每次都能「复制那段话」）、卡列表（搜索/排序/只看还能用的、剩≤3 次黄、用完停用到期红）、停用/启用/吊销（吊销要确认）、本机留底、中转自检 |
| `relay/card-text.js` | 「发给同学的那段话」抽成一份，**CLI 与控制台共用**（0.1.28 就是两边写歪才让同学照着做失败） |
| `relay/admin-client.js` | 管理接口客户端 + 凭据解析（环境变量 → `relay/admin-secret.local.txt`） |
| `scripts/card-cli.cjs` | 改为用上面两个共用模块，命令与输出不变 |
| `tests/console-check.cjs` | 第 11 个套件（12 项）：只绑本机 / 钥匙头 / Host 校验 / 预检 403 / **页面里没有口令** / 列表 / 发卡与那段话 / 停用启用吊销 / 留底 / 自检 / **日志里没有卡号明文** |
| `relay/cards.local.jsonl` | 控制台自己发的卡号留底（gitignored，等于凭据） |

**顺手修掉一个老坑**：`.gitignore` 末尾那段中文注释是 **GBK 坏字节**（文件整体是 UTF-8，
只有那一行不是）—— `read`/`grep` 这类工具直接读不了它。已按正确编码重写，并把
`adapter-unit` 的"仓库文本文件是合法 UTF-8"守卫**扩到根目录无扩展名文件**（`.gitignore`
这类以前不在扫描名单里，所以漏过了）。

**实测**（只读，不打任何凭据）：本机口令读到了；中转 `healthz` → `ok:true / store:cloudbase-pg /
upstreamKeySet:true / adminEnabled:true`；账本 6 张卡、全部还能用、累计 11 次调用（上限合计 270）。
> 顺手看到一条可疑现象：**11 次调用记到了次数、token 用量却是 0**。卡现在按"次数"限额，
> 所以不影响使用；但如果以后想按 token 限额，得先查清这条（可能是上游没回 usage，
> 或流式那帧没被解析到）。
