## P0-1 多视口布局回归 ✅

**新增** `tests/viewport-check.cjs`（25 项，已加入 `npm test`）。
自带静态服务与假模型端点，覆盖 1440×900 / 1280×800 / 768×1024 / 390×844 / 320×568。

**它当场抓到两个真实缺陷**（都已修）：

1. **平板 768px 下发送键被压成 23px 宽** —— `.send-button` 的 44px 规则只在 760px 以下生效，
   而 `.composer-footer` 是 flex，按钮被压缩。修法：基础规则加 `flex: 0 0 auto`。
2. **「记错 / 编造」按钮命中区只有 22×14** —— 鼠标都难点、触屏更点不到。
   修法：基础提到 26×24，窄屏（≤760px）提到 44×44。
   窄屏判据用**宽度**而不是只看 `(hover: none)`：实测无头 Chrome 把 hover 报成 hover，
   只按媒体查询会让手机拿到小按钮。

**顺带修掉一个我自己造成的事故**：之前用 PowerShell 追加中文 CSS 注释时被写成 **GBK**，
`app/styles.css` 混进 **153 处非法 UTF-8 字节**（浏览器把中文注释全变乱码、编辑器打不开该文件）。
已按 GBK 解码后重写为 UTF-8。

**并加了一条永久防线**：`adapter-unit` 新增「仓库文本文件是合法 UTF-8」用例，
逐字节校验 `app/`、`tests/`、`docs/` 下所有文本文件。已用"故意植入坏字节"验证它真的会报错
（既有的 BOM 检查抓不到这种编码错误）。

**提交**：`fd275aa`（修复）、`72c9961`（清理误提交的临时文件）
**测试**：adapter-unit 69/69、memory-unit 25/25、search-unit 15/15、metrics-unit 13/13、

## P0-2 / P0-3 / P0-4 数据完整性 · 压力 · 隐私出口 ✅

**新增** `tests/data-integrity.cjs`（10 项，已加入 `npm test`），自带静态服务与假模型端点。

### P0-2 存档往返

- 导出再导入后，记忆的**来源元数据一字不差**（主题 / 替换记录 / 来源对话 / 消息序号 / 时间戳 / 来源标记）；
  对话正文与角色卡名称同样保留。
- **抓到一个真隐私问题并修掉**：`exportAll()` 会把 `kv` 里的 `secrets` 一起导出 ——
  也就是**存档 zip 里带着明文 API Key**。存档是用户会随手发出去的东西，这等于把凭据送人。
  修法：导出时跳过密钥键，并在导出提示里写明"存档里不含 API Key，换机器后需要重新填一次"。

### P0-3 长对话压力（800 轮 / 1601 行 / 198 KB）

实测：写入 **5ms**、列表 **1ms**、读取 **2ms**；1600 条消息里检索 **9ms** 且命中的是目标那一轮；
界面上仍能打开、能发送、台账照常记一轮。**没有发现性能问题。**

### P0-4 隐私出口

- 请求体里**没有 API Key**；
- 甲角色的请求里**没有乙角色的对话与记忆**（角色隔离在出口处也成立）；
- 请求体里没有本机偏好字段（preferences / 教学状态 / 侧栏选择 / 称呼）；
- 请求体是干净的 OpenAI 形状：SillyTavern 时代的内部字段被适配层剥掉了；
- 全部请求只发往一个路径。

**提交**：`12db082`（含隐私修复）、`d0e4c60` 之后的清理提交
**测试**：全套 8 个套件全绿（69 / 25 / 15 / 13 / 14 / 39 / 25 / 10）
