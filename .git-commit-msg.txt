feat: 记忆可见可改可删 + 上下文预算 + 历史检索 + 每轮指标台账

这一批围绕「聊天更可靠、看得见」做了四件事。

1) 记忆（阶段③）
- 新增 memory-core.js：每条记忆记下来源（哪段对话第几条、时间、谁写的）
- 「本次请求」里点开记忆书能看到每一条；新增「角色记忆」面板可改可删，
  删除后后续请求真的不再带上它
- 同一主题的新记忆会替换旧的（用户改口时不再两条并存）；
  主题带锚点与同义词归一（称呼/名字、饮料/喝的算同一件事）
- 真实信息与虚构剧情分开存：剧情片段（动作、旁白、战斗、魔法）确定性拒收，
  拒收会告诉用户，不静默丢弃

2) 上下文（阶段②）
- 旧对话从「写死最近 16 条」改为按 token 预算回填；默认不限制（全部带上），
  依据是官方 1M 上下文 + 缓存命中计价（已发过的内容再发约为原价 1/50）
- 真要截断时，面板写明「未带上：更早的 N 条消息」

3) 「本次请求」面板
- 按来源分段（角色卡各段 / 世界设定 / 每本记忆书 / 回复格式 / 旧对话 / 本轮输入），
  每段给字符数与 token
- 自带逐字节自检：分段之和必须等于真正发出的请求，不等就标红说明这份数字不可信

4) 可靠性与指标（阶段④）
- 保存加重试幂等：同一次发送重发不会写两遍、不再重复计费
- 半截记忆标记（[[记住:）在流式渲染与保存两处都被丢掉
- 新增 search-core.js：跨全部对话的关键词检索（不使用向量库），结果带出处；
  翻不到时明确告诉模型「没有记录，不要编造」
- 模型可主动再翻一次历史（[[搜索: 关键词]]，一次最多 2 条，晚一轮见效）
- 诚实规则区分「眼前的对话」与「以前的记录」，不再让模型否认刚说过的话
- 新增 metrics-core.js：每轮记首字延迟 / 整轮延迟 / token / 费用 / 记忆与检索行为；
  记错与编造只由用户手动标记，机器不自动判定

顺带修掉的真问题
- 英文角色卡因为玩家说中文就切成中文（卡上缺语言标记 + 语言要求被格式指令盖过）
- 设置改完立刻发送用的是旧值（整量重读把新值覆盖回去）
- 内容包升级时包自带卡不会刷新（老存档没有来源标记，永远跳不到刷新分支）
- 新增 scripts/set-card-language.cjs：给卡片 PNG 补语言标记，图像字节原样保留
