角色世界

本地优先的开源角色对话应用。数据、密钥、对话记录都只存在你自己的设备上。

它是怎么运行的

这个应用没有服务器，也没有账号系统。角色卡、对话记录、记忆书保存在浏览器/应用的本地数据库里； 你要配置一个模型接口（DeepSeek 官方、OpenAI 兼容端点，或者你自己电脑上的 llama.cpp）， 请求从这台设备直接发出去。

因此：没有人能替你看到对话，也没有人能替你删掉它。代价是重装系统前记得自己导出备份。

「本地保存」不等于「不上云」

这句话要说清楚，免得你以为对话完全没有离开这台设备。实际情况是：

  • 只有一份请求会离开设备：发给你自己配置的那个模型端点。 它的内容是——角色卡（设定/描述/性格/场景）、该角色的记忆书条目、最近这段对话、 需要的旧对话片段，以及你这一轮输入的内容；
  • 如果那个端点是云端服务（例如 DeepSeek 官方），上面这些内容就会到达对方服务器并按对方的条款处理。 想完全不出去，只能用你自己电脑上的本地模型（llama.cpp 等）；
  • API Key 只在你的设备上保存，发请求时作为鉴权头发给你配置的那个端点。 除此之外不会发往任何地方，也不在导出的存档里（换机器要重新填一次）；
  • 不发送：其他角色的对话与记忆、界面偏好、主题与缩放、引导状态、本机路径。 这几条都有自动化用例逐条断言（见下方「最近一次全量测试」）；
  • 应用本身没有任何统计、上报、崩溃收集。

「发送前预估」那一行就是让你在按发送之前，先看清这一轮大概会带多少内容出去。

已知的限制（不是 bug，但你需要知道）

  • 历史检索是关键词匹配，不是语义搜索。你问"我上次说的那个喝的"， 它不一定翻得到"咖啡"；翻不到时它会照实说没有更早的记录，而不是编一个；
  • "这是剧情还是你的事实"是启发式判断。它宁可漏掉一条剧情， 也不会拿模型编的剧情去覆盖你说过的事实；
  • 伴侣模式那几条硬规矩是写在提示词里的，能大幅降低但不保证 100% 杜绝 内疚话术。所以面板里带一个自检：把最近回复里像内疚话术的原话点出来给你看（只报告，不改写）；
  • 输出长度不按模式硬压：剧情模式页与伴侣模式都靠提示词约束 + 记录实测长度， 撞上输出上限时会明确告诉你「被截断了」并给一个「接着说」（而不是让你看一句半截的话）。 想让回复短一些，可以在「设置 → 模型 → 生成参数」里填一个输出上限；
  • 生成参数只有一层定义：渠道默认 → 用途（对话页/伴侣/剧情页）→ 你的预设或手填。 所以"稳一点/活泼一点"是一个预设，而不是每个页面各存一份数（同一个数字有两个来源这种事， 这个项目踩过坑）；
  • 没有跨设备同步。换设备靠导出/导入存档；
  • 离线包：网页版可以装到桌面/手机，断网时也能打开界面并读到本机数据 （外壳按"网络优先"缓存，所以有网时永远是最新版，不会出现"改了却看不到"； 没有网络时会用最后一次成功打开的那份界面，对话内容本来就在本机）；
  • 没有主动提醒。应用不会在你没打开的时候唤起你，也不做连续打卡、好感度、冷落惩罚 —— 这条有自动化用例盯着（离线壳里也不允许有推送/通知/后台同步的入口）；

仓库内的 packs/ 目录可能包含由社区制作的同人角色卡（例如《哈利·波特》相关角色）。 这些内容属于原作者的衍生同人创作：

  • 相关角色与世界观版权归原作者及权利方所有，本项目与权利方无任何关联，也未获得其授权或背书；
  • 如果你是权利方并希望移除某份内容，请在仓库提 issue，我们会立即删除。

不想看到这些内容也很简单：删掉 packs/ 下对应的目录，或者在设置里停用该内容包。 应用本身不含任何角色数据。

你的数据在哪里

  • 角色卡、对话、记忆书：本机数据库（浏览器为 IndexedDB；桌面端是应用数据目录下的普通文件， 可以直接用资源管理器备份）；
  • 关系档案（伴侣模式）：同样在本机数据库里单独存一份，不放进记忆书 —— 你亲手写的真实信息和模型自己记的东西分开存，「清空记忆」不会碰它；
  • API Key：本机数据库明文保存，发请求时作为鉴权头发给你配置的那个端点（详见上面「本地保存不等于不上云」）。 任何能打开这台设备的人都能读到它 —— 公用电脑上请不要保存密钥；
  • 界面偏好与当前模型选择：本机 localStorage。

换电脑或换浏览器时，用「设置 → 本地数据」里的导出/导入迁移。 导出的存档里不含 API Key，也不含界面偏好。
