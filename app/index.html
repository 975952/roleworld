    体验卡没有使用体验卡

    体验卡走的是发卡人搭的中转：对话内容会经过那台中转服务再送到模型，卡号只存在你的本机、不进导出存档。中转那边能看到"这张卡用了多少次"，本项目的中转实现不记录聊天正文。换设备 / 换浏览器要重新粘一次：必须带上中转地址（发卡人给你的那一整行 卡号@中转地址，或整条链接），只给卡号是不够的。

    API Key正在读取…

    每一家服务商的 Key 存在各自的格子里：换了服务商要重新填一次，否则会用上一个服务商的 Key 去请求（会 401）。
